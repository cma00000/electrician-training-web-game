火线 / 零线 / 地线

北美住宅与轻型商业：Hot（黑/红）带电送出，Neutral（白）回流，Ground（绿/裸）仅作故障保护通路，正常情况下不载流。240V 单相设备使用两根火线（L1-L2），相间电压 240V。

考题常以导线颜色与功能配对的形式出现：设备接地导体（EGC）= 绿色或裸铜，接地中性线（Grounded Conductor）= 白色/灰色。

断路器的作用

断路器保护的是导线不过载，不是保护电器。导线允许载流量必须 ≥ 断路器额定值。

三步走

① 求电流：I = P ÷ V　② 连续负载（持续 ≥3 小时）按 I × 125% 选保护；等价说法：断路器持续负载不得超过额定值的 80%。　③ 按断路器选不小于其额定的导线。

商用厨房 GFCI

NEC 210.8(B)：商用厨房内 125V 15/20A 插座必须有 GFCI（接地故障断路器）保护——水与电共存的区域，人身保护优先。

专用回路（Individual Branch Circuit)

固定安装的大功率厨房设备（油炸锅、烤箱等）应使用专用回路，不与照明或普通插座共用，避免互相影响并便于检修隔离。

80% / 125% 规则

NEC 210.19 / 210.20：连续负载下导线与过流保护均按 125% 取值。

验收检查（Inspection）类考题常考：GFCI 适用场所、回路是否专用、导线-断路器匹配。违规 = Fail Inspection = 返工。

分段电压测量法

从电源侧向负载侧逐点测电压：配电箱 → 接线盒 J1 → 接线盒 J2 → 设备端。电压「消失」的那一段就是故障区间——常见原因：接头松动、断线、端子氧化。

例：配电箱 240V ✓ → J1 240V ✓ → J2 0V ✗ ⇒ 故障在 J1 与 J2 之间（多为 J2 进线端子松动）。

排障题在 C-10 实务部分常以「给读数、判位置」的形式出现。记住口诀：有压到哪里，故障在下一段。

安全第一

带电测量使用万用表；紧固端子前必须断开断路器并验电确认无电（Lockout/Tagout 思想）。
